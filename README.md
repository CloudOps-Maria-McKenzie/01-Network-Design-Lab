# Network Design Lab

## Project Overview

This project demonstrates the design and implementation of a small business network using Cisco Packet Tracer.

## Technologies

- Cisco Packet Tracer
- Routing
- Switching
- VLANs
- DHCP
- DNS

## Project Status

Planned

## Goals

- Design a secure business network
- Configure VLANs
- Configure routing
- Test connectivity
- Document troubleshooting procedures
